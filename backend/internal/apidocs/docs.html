Getting started

The base address is {{.Server}}. Two requests that need nothing at all, to see the shape of things:

curl -X POST {{.Server}}/api/preview \
  -H 'Content-Type: application/json' \
  -d '{"format": "round_robin", "teams": 4}'

curl '{{.Server}}/api/collections/tournaments/records?perPage=5'

Everything that writes needs a token. Sign in for one, then send it on every request:

curl -X POST {{.Server}}/api/collections/users/auth-with-password \
  -H 'Content-Type: application/json' \
  -d '{"identity": "you@example.com", "password": "…"}'

curl -X POST {{.Server}}/api/stages/STAGE_ID/generate?dry_run=1 \
  -H 'Authorization: Bearer TOKEN'
